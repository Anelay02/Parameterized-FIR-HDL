# Parameterized-FIR-HDL

A collection of **parameterizable FIR (Finite Impulse Response) filters** implemented in **Verilog and VHDL**, using well-known window functions for filter coefficient design.

The goal of this repository is to provide reusable, configurable FIR filter implementations suitable for **FPGA and digital hardware designs**.

> 🚧 **Work in Progress**
>
> This repository is actively being developed. More filter architectures, window functions, testbenches, and documentation will be added over time.
